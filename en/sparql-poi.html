SPARQL Queries

In this section, several examples of SPARQL queries used for the exploration of the national POI-AP_IT ontology are presented.

General Exploration of the POI-AP_IT Ontology

The following query was used to obtain a general view of the resources belonging to the POI-AP_IT ontology, querying the national endpoint and filtering the subjects on the ontology's namespace:

PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT DISTINCT ?s ?p ?o
WHERE {
  ?s ?p ?o .
  FILTER(STRSTARTS(STR(?s), "https://w3id.org/italia/onto/POI"))
}
LIMIT 100

This query uses DISTINCT to avoid duplicates and FILTER to restrict the domain only to the resources of the POI-AP_IT ontology, returning a sample of the available triples (limited to 100 results).

Identification of Available Classes

To identify the classes defined by the POI-AP_IT ontology and gather descriptive information (labels and comments), the following query was used:

PREFIX owl:  <http://www.w3.org/2002/07/owl#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT DISTINCT ?class ?label ?comment
WHERE {
  ?class a owl:Class .

  OPTIONAL { ?class rdfs:label ?label . }
  OPTIONAL { ?class rdfs:comment ?comment . }

  FILTER(STRSTARTS(STR(?class), "https://w3id.org/italia/onto/POI/"))
}
ORDER BY ?class
LIMIT 100

In this case, OPTIONAL is used to retrieve labels and comments when available, without excluding classes that lack them, while ORDER BY allows sorting the classes by IRI, facilitating their consultation. The query made it possible to identify the reusable classes in the project and document their semantic meaning before proposing a local extension.

Identification of Reusable Properties

To analyze the properties defined in POI-AP_IT (both owl:ObjectProperty and owl:DatatypeProperty), the following query was employed:

PREFIX owl:  <http://www.w3.org/2002/07/owl#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT DISTINCT ?property ?label ?comment ?domain ?range ?type
WHERE {
  ?property a ?type .

  FILTER(?type IN (owl:ObjectProperty, owl:DatatypeProperty))
  FILTER(STRSTARTS(STR(?property), "https://w3id.org/italia/onto/POI/"))

  OPTIONAL { ?property rdfs:label ?label . }
  OPTIONAL { ?property rdfs:comment ?comment . }
  OPTIONAL { ?property rdfs:domain ?domain . }
  OPTIONAL { ?property rdfs:range ?range . }
}
ORDER BY ?property
LIMIT 100

FILTER is used both to filter the type of property (ObjectProperty or DatatypeProperty) and to delimit the namespace of interest, while the OPTIONAL clauses allow retrieving metadata useful for reuse (domain, range, labels, comments). This query was fundamental for selecting the properties to reuse in mapping the Bolognese datasets, avoiding the redundant definition of local properties.

Search for Concepts Potentially Relevant to Bologna

To verify the possible presence, within the national ontology, of concepts related to Bolognese urban services or items of urban furniture, a query was defined that combines multiple patterns and makes use of REGEX:

PREFIX owl:  <http://www.w3.org/2002/07/owl#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX dct:  <http://purl.org/dc/terms/>

SELECT DISTINCT ?resource ?type ?label ?comment ?description
WHERE {
  {
    ?resource a owl:Class .
    BIND("Class" AS ?type)
  }
  UNION
  {
    ?resource a owl:ObjectProperty .
    BIND("ObjectProperty" AS ?type)
  }
  UNION
  {
    ?resource a owl:DatatypeProperty .
    BIND("DatatypeProperty" AS ?type)
  }

  OPTIONAL { ?resource rdfs:label ?label . }
  OPTIONAL { ?resource rdfs:comment ?comment . }
  OPTIONAL { ?resource dct:description ?description . }

  FILTER(STRSTARTS(STR(?resource), "https://w3id.org/italia/onto/POI/"))

  FILTER(
    REGEX(STR(?resource),    "Bologna|TPER|bench|panchina|toilet|bagno|parking|parcheggio|portico|bus stop|fermata|arredo", "i")
    ||
    REGEX(STR(?label),       "Bologna|TPER|bench|panchina|toilet|bagno|parking|parcheggio|portico|bus stop|fermata|arredo", "i")
    ||
    REGEX(STR(?comment),     "Bologna|TPER|bench|panchina|toilet|bagno|parking|parcheggio|portico|bus stop|fermata|arredo", "i")
    ||
    REGEX(STR(?description), "Bologna|TPER|bench|panchina|toilet|bagno|parking|parcheggio|portico|bus stop|fermata|arredo", "i")
  )
}
ORDER BY ?type ?resource
LIMIT 100

The query uses UNION to simultaneously consider classes, object properties, and datatype properties, and filters the results through multiple regular expressions on IRIs, labels, comments, and descriptions, aiming to intercept any resource containing references to Bologna, TPER, urban furniture, toilets, parking lots, or porticoes. The results confirmed the absence of specific support for many of the urban categories of interest, motivating the design of a local ontological extension.
