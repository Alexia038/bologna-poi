Generated RDF Triples & LLM Results

In this section, we present in detail the results and practical examples of the RDF triples generated by the large language models (LLMs) during the experiments. The results are organized according to the LLM model used, illustrating the behavior and the generated code for each prompting technique.

1. Results — Gemini Pro

Zero-Shot Prompting

With the zero-shot prompt, Gemini Pro generated a set of RDF triples in Turtle format using the classes and properties defined in the local ontology. The model produced representative examples of the main categories present in the dataset, including instances of bo:Bin, bo:Bench, bo:Fountain, bo:PublicToilet, bo:Portico, and bo:BusStop.

For each instance, the properties deemed relevant were populated (e.g., bo:hasCoordinates, bo:hasMaterial, bo:hasCost, bo:hasBusStopCode). The model also provided a description of the adopted mapping process, illustrating how the values from the "Tipologia POI" column were used to identify the most appropriate ontological class.

Few-Shot Prompting

With the few-shot prompt, Gemini Pro processed the entire CSV file (13,461 POIs) and generated the entire dataset in RDF Turtle format. The model automatically classified the instances into the subclasses of the ontology based on the value of the Type field. Below are examples of the triples generated for the various categories:

Zero-Shot Chain-of-Thought

With the chain-of-thought prompt, Gemini Pro returned an output that explicitly documents the reasoning carried out for each category of the CSV before producing the triples. The model identified the 4 main categories present in the "Tipologia POI" column. For example, for an item of urban furniture, the model constructed the URI starting from the ontology base, selected bo:Bin as the most specific class (subclass of bo:UrbanFurniture), and associated the relative datatypes.

2. Results — ChatGPT Plus

Zero-Shot Prompting

ChatGPT Plus responded by generating the entire Turtle file from the CSV, named df_POI_triples.ttl, covering all 13,461 points of interest present in the dataset and producing a total of 141,826 RDF triples. The model independently interpreted the structure of the CSV and mapped each row to the class and properties of the ontology, without receiving guided examples.

Few-Shot Prompting

Unlike Gemini Pro, with the same few-shot prompt, ChatGPT Plus did not process the entire CSV, but limited itself to producing representative examples per category, respecting the classes and properties of the provided ontology and using the correct prefix bo::

@prefix bo: <http://dati.comune.bologna.it/ontology/bologna-poi#> .

Zero-Shot Chain-of-Thought

The observed behavior is substantially analogous to that of Gemini Pro. ChatGPT Plus pre-identified the categories present in the dataset, made explicit the process of selecting ontological classes and properties, and subsequently produced examples of RDF triples consistent with the structure of the ontology. The use of this technique led to the generation of an output divided into two distinct phases: a preliminary phase of data analysis and reasoning, and a final phase of producing the RDF triples.
